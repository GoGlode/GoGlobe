## Статус реализации

Это целевой контракт для дальнейшей разработки. Публикация документов **не означает**, что текущий backend уже реализует `/api/v1`, Trip, Calendar, гостевые сессии и восстановление.

Текущий демонстрационный API `/api/search` описан в [историческом контракте v0](../api-contract.md). Его фактическая схема определяется кодом сервера и `/openapi.json`. До миграции не подключайте клиент нового формата к старому backend без адаптации.

PDF объясняет поведение, OpenAPI задаёт точные поля, моки позволяют разрабатывать frontend параллельно с backend. Новые несовместимые изменения согласовываются между потребителями API; схема, примеры, тесты и документация обновляются вместе.
