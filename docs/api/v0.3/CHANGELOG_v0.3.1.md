# API v0.3.1

Аддитивное расширение v0.3 добавляет `POST /intent/preview`.

- Preview принимает исходный запрос и опциональные `Params`.
- Ответ содержит проверенный разбор, не более трёх вопросов и режим анализа.
- Preview не создаёт `Search` или `Trip` и не запускает поиск тарифов.
- `preview_id` не передаётся в `PlanRequest`; итоговый запрос и выбранные параметры
  повторно валидируются при `POST /searches`.
- При недоступности LLM используется детерминированный `analysis_mode=fallback`.
- Preview ограничен 20 запросами в минуту на owner; ответ `429` содержит
  `Retry-After` и валидный `ErrorResponse`.

Все 27 операций базового v0.3 и их схемы остаются совместимыми.
