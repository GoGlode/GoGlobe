# Frontend: экраны, владельцы, правила

Источник визуала — макеты дизайнера + пакет `GoGlobe_ClaudeCode_Assets_v2` (лежит в `frontend/public/assets`: brand, icons, images).
Приложение — **мобильная колонка** (≤430px) по центру, стеклянная нижняя навигация, светлая тема. Токены: `src/design/tokens.css`.
Данные пока демо (`src/data/trips.ts`) — цены, рейтинги и фото **не реальные** (фото — концепт-изображения). Источник правды по формату — `src/data/types.ts`.

## Общее (в `main`, меняется только через PR с ревью обоих фронтов)
`src/ui/*` (Icon, GlassNav, AppShell, PageHeader, Rating, Photo) · `src/design/*` · `src/data/*` · `src/state/*` · `App.tsx` (роуты)

## Правила
1. Свои экраны правим только в своих файлах; общие (`ui`, `data`, `state`, `App.tsx`) — отдельным маленьким PR в `main`.
2. Нужна новая иконка — добавить в `ui/Icon.tsx` (не дублировать в фичах).
3. Цвета/радиусы/тени — только токены `var(--…)`.
4. Состояния обязательны: загрузка, пусто, ошибка.
5. Не показываем демо-цифры как проверенные — в UI у демо-данных подпись «Демо-данные».
6. Интеграция с API — через `data/api.ts` (адаптер Offer → Trip), экраны не знают про backend.
